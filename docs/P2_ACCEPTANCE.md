> 跟踪「P2 是否像 P1 一样可玩」。照表测，回填状态列。
> 状态：☐ 未测 · ☑ 通过 · ✗ 失败（后面写现象，必要时附 `Player.log` 行号/关键字）
> 每项都请顺手扫一眼 **P1 回归**（P1 自己做同样动作是否仍正常、HUD 不被 P2 污染）。
